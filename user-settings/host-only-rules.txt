# Host-only rules: a permissions.allow rule that matches any line here stays
# in hosts/<HOST>.json, the Mac that approved it. Every other exact
# Bash(...) rule goes to the host's group file (scripts/harvest-user-settings.sh).
#
# One POSIX ERE per line; blank lines and lines starting with # are ignored.
# Each line is matched, ignoring case, anywhere in the full rule text, so
# "Bash(sudo rm x)", "Bash(cd x && rm y)" and "Bash(xargs rm)" all match rm.
# A false positive only keeps a rule on one Mac; a false negative grants it to
# every Mac in the group. When unsure, add a line.
#
# Word edges use [^A-Za-z0-9_] (no \b: BSD and GNU grep differ), so rm does
# not match "perform". A "-" counts as an edge, so ssh matches ssh-keygen.
# Use [[:space:]], not \s.
#
# The harvest also keeps these on the host in code, whatever this file says:
# any rule that is not Bash(...), and any Bash rule holding a *. A missing,
# unreadable or invalid file keeps every rule on the host.

# ── Delete, move, overwrite ──
(^|[^A-Za-z0-9_])rm([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])rmdir([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])unlink([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])shred([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])truncate([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])mv([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])cp([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])dd([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])ln([^A-Za-z0-9_]|$)
(^|[^A-Za-z0-9_])tee([^A-Za-z0-9_]|$)
# In-place edits overwrite the file.
(^|[^A-Za-z0-9_])(g?sed|perl)([^A-Za-z0-9_].*)?[^A-Za-z0-9_]-[A-Za-z]*i
# A shell redirect overwrites or appends; this also keeps "2>&1" rules local.
>
(^|[^A-Za-z0-9_])find([^A-Za-z0-9_].*)?[^A-Za-z0-9_]-(delete|exec|execdir|ok|okdir)([^A-Za-z0-9_]|$)
